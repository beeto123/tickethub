# 🎫 TicketHub

A modern ticket resale platform for events, concerts, sports, and more.

## 🌟 Features

- 🎟️ **Ticket Management** - Add, edit, and delete tickets
- 💰 **Multi-Currency Support** - USD, EUR, DKK, NOK, SEK, and more
- 🔗 **Individual Ticket URLs** - Each ticket gets its own SEO-friendly link
- 💳 **Payment Integration** - Mercuryo payment links for each ticket
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🔒 **Admin Panel** - Secure ticket management
- 🏷️ **Mark as Sold** - Track sold tickets
- 🔍 **SEO Friendly** - Clean URLs for better search visibility

## 🛠️ Tech Stack

- **Frontend**: React.js + Tailwind CSS + Vite
- **Backend**: Node.js + Express
- **Database**: Supabase (PostgreSQL)
- **Image Hosting**: Cloudinary
- **Payments**: Mercuryo
